To run, copy the linux_packet_spam Ansible role and use the command 'ansible-playbook -i inventory.ini lps.yml'. Modify the IP addresses in inventory.ini for the corresponding systems. This script runs uses Ansible Playbook, creating a IP spammer script on all target Linux machines in [linux_boxes] to send pings against every IP address listed under [all] every 20 seconds, and launching the script through Ansible Playbook using a nohup + watch command to hide the running terminal and loop execution.
